# Accessibility (WCAG 2.2 AA)

- Every form control (`input`, `select`, `textarea`, custom control) has an accessible name: a `<label>` bound to it, `aria-label`, or `aria-labelledby`. A placeholder is not a label.
- Every icon-only button or link has an accessible name.
- An informative image has non-empty `alt` (or an accessible name). A decorative image has empty `alt=""` (or `aria-hidden="true"`).
- Anything clickable is a native `button` or `a`, or has a role, `tabindex="0"`, and a key handler for Enter (and Space for buttons). No click handler on a plain `div` or `span` without those.
- Do not remove the focus outline (`outline: none`, `outline: 0`) without a visible replacement focus style on the same selector.
- Do not use a positive `tabindex`.
- When the project defines colour tokens or a theme, new component code or styles use them, not new hex, `rgb()`, `hsl()`, or named-colour literals (contrast is checked in one place, the tokens). With no tokens or theme, this rule does not apply.
- Add `role` or `aria-*` only when no native element expresses the same thing (for example `role="button"` on a `div` where `<button>` works, or `role="navigation"` on a `div` where `<nav>` works, is a violation).
- Page language and document title exist where the diff adds a page or document shell: `lang` on `<html>`, a non-empty `<title>`.
