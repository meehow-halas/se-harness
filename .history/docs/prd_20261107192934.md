Project name: dev-harness
Project description: This is a project intended to become a "harness layer" in the future. It will provide skills, agents, rules, and workflows for managing and developing software engineering projects

How it will run:
It will be installed with npm, either from npm registry or github repository with npm install. After that it will be available in the system by accessing command 'dhs'

Feature management
1. files - specs, prompts and logs are stored in files
   docs/features/
   docs/prompts
   docs/features-log
2. Jira - specs, prompts and logs handled with Jira MCP

Tracking features with files is the default, jira is optional.

dhs commands
1. install/uninstall - indempotent, installs/uninstalls dhs on the machine
